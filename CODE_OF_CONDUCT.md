# Code of Conduct

## Our Pledge

LAPANG exists to protect children. Every contributor, user, and community member is expected to uphold the highest standards of ethical conduct, professionalism, and respect for the sensitive nature of this project.

## Standards

**Expected behavior:**

- Treat all contributors with respect and professionalism
- Handle all test data, case simulations, and documentation involving minors with the utmost sensitivity
- Prioritize user privacy and data protection in all contributions
- Provide constructive, actionable feedback during code reviews
- Report security vulnerabilities through responsible disclosure channels

**Unacceptable behavior:**

- Using project infrastructure, test environments, or APIs for anything other than legitimate development and testing
- Distributing or exposing real personal data of any individual through the platform
- Harassment, discriminatory language, or personal attacks in any project communication channel
- Publishing private information of others without explicit consent

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainer. All reports will be reviewed promptly and treated with confidentiality.

The project maintainer reserves the right to remove, edit, or reject any contributions that violate this Code of Conduct, and to temporarily or permanently ban any contributor whose behavior is deemed harmful.
